# Internee_LMS_Learning_App

A Flutter-based mobile application designed to provide easy access to Internee.pk LMS courses and learning resources.

## Features

- Browse available courses directly from the Internee.pk LMS platform.
- Watch video lectures using an integrated video player.
- Attempt quizzes and receive real-time scores.
- Track learning progress.
- User authentication using Firebase.
- REST API integration for LMS course access and quiz management.
- Smooth and interactive learning experience.

## Technologies Used

- **Flutter:** Cross-platform mobile application development.
- **Dart:** Programming language used for app development.
- **REST APIs:** Integration with the Internee.pk LMS platform.
- **Firebase:** Authentication and backend services.

## Getting Started

To get started with this project, follow these steps:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd internee_lms_learning_app
   ```

3. Install the required dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## Project Objective

The main objective of this application is to make online learning easier and more accessible for students and interns by providing course browsing, video lectures, quizzes, and progress tracking in one mobile application.
